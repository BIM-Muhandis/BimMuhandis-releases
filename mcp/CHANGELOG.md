# BIM Muhandis MCP — oxirgi versiya

## 1.10.0 (15.11.2026)

BIM Muhandis MCP — AI ilovalar (Claude, ChatGPT, Gemini, Microsoft Copilot, Grok, Kimi, Qwen, Meta Muse, DeepSeek, Perplexity, Cursor, Windsurf, LM Studio, Cline) uchun Revit, AutoCAD / Civil 3D, Navisworks, Tekla Structures, SketchUp, LIRA-SAPR, SCAD Office, SAP2000 / ETABS, Robot, SOLIDWORKS, Photoshop, CorelDRAW 2022–2027 va Word / Excel / PowerPoint ulagichi.

O'rnatish: ZIP'ni chiqarib oling → «BIM Muhandis MCP - O'rnatish.exe» → Claude va Revit'ni qayta oching. AI ilovalar o'zi ulanadi. To'liq o'chirish: «BIM Muhandis MCP - O'chirish.exe».

- Ixcham rejim — AI'ga eng kerakli tool'lar (ochiq dasturlar, ko'p ishlatilganlar) ko'rsatiladi, qolgan hammasi (~620) aqlli qidiruv bilan: javob tezroq, token kam, DeepSeek/Kimi/Qwen kabi modellar kam xato qiladi; qidiruv o'zbek, rus va ingliz so'zlarini tushunadi, noto'g'ri nomga eng yaqinini taklif qiladi, yetishmagan parametrni aniq aytadi; uzun natijalar qisqartiriladi (Sozlamalar → «To'liq ro'yxat»)
- barcha tool'larga to'liq annotations (o'qish tool'lari ruxsat so'ralmasdan ishlaydi)
- MCP hech qachon ruxsat so'ramaydi: «AI ko'p elementni o'zgartirmoqchi» va «C# kodi modelni o'zgartirdi» oynalari olib tashlandi; Esc ×3 — AI darhol to'xtaydi (oynasiz, qaytarish Ctrl+Z)
- o'ng pastda AI holati: yashil ✓ + AI nomi (ulandi / ishlamoqda), qizil ramka — uzildi; × — yashirish
- dasturlarni AI o'zi ochadi: bm_list_apps, bm_launch_app (Revit, AutoCAD, Navisworks, Tekla, SketchUp, LIRA, SCAD, SAP2000, ETABS, Robot, SOLIDWORKS, Photoshop, CorelDRAW, 3ds Max, Office) — ish stolidagi yorliq bilan (dastur tili saqlanadi), MCP ulanguncha kutadi
- yangi ulagichlar (COM, plaginsiz): SAP2000 / ETABS (model, kesim, tayanch, yuk, hisob, kuchlar, ko'chishlar, reaksiyalar), Robot (tugun, sterjen, hisob, natijalar), SCAD Office (fayllar va natija jadvallari), SOLIDWORKS (ochish, PDF/STEP/DXF eksport, xossalar, massa, makros), Photoshop (render ishlovi, o'lcham, eksport, JavaScript), CorelDRAW (planshet: import, matn, shakl, PDF/PNG)
